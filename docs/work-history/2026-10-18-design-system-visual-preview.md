# 모바일 디자인시스템과 시각 미리보기

사용자는 원문을 나열하는 조회 화면은 모바일에서 이해하기 어렵다고 지적하며 UX/UI 개선과 preview.html 시각화를 함께 요청했다.

기본 진입을 토큰 목록에서 실제 preview.html로 바꿨다. 프로젝트 선택, 조회 종류를 먼저 두고 커밋·원본 경로는 펼침 영역으로 옮겼다. 토큰 목록에 라이트/다크 값과 색상 견본을 표시하고, 상세에서는 용도를 먼저 읽고 원본/참조는 펼쳐 본다. 화면 예제는 HTML title로 찾고 실제 화면을 먼저 연다. 이전 ?q= 검색 주소도 토큰 검색으로 유지한다.

새 DesignPreview는 백엔드 owner-only `/api/design-systems/{system}/preview`의 같은 커밋 HTML 번들을 사용한다. 라이트·다크 선택, 제목별 구간 이동, 네이티브 dialog 크게 보기, 원문 전환, 초기 상태 복원을 제공한다. 예제 스크립트는 `sandbox="allow-scripts"`의 opaque origin에서만 동작한다. 미리보기는 서버 빌드/실행과 별개다. 일부 원본 예제는 좁은 폭에서 자체 가로 스크롤을 요구한다.

검증과 범위: Run outbox `474a19c0-1b82-4ece-9be4-0e5ca2ac9131`의 테스트 로그·브라우저 스냅샷·계측 JSON을 참고한다. 실제 PageHeader·CSS·조회 컴포넌트와 Git 원본을 연결한 루프백 검증 화면에서 측정했다. 운영 로그인은 별개이며 실제 iOS Safari/PWA는 미검증이다. collectPage가 접근 못 하는 opaque iframe은 원본 안의 별도 계측으로 부모 접근 차단·이미지 로드·테마를 확인했다.

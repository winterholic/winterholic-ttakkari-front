# 2026-10-19 원격 데스크톱 모바일 조작 개선

- 사용자 피드백: 아이폰에서 실제로 접속은 됐지만 조작이 너무 불편함. 게임 컨트롤러식 조작, 적당한 커서 크기, 전반적 사용성 개선 요청.
- 커서 크기 원인(코드 기준): 로컬 커서가 화면 배율과 무관하게 `--tk-space-5`(20px) 지름 원이었고 Mac 화살표와 모양이 달랐다. noVNC 는 터치 기기에서 서버 커서 이미지를 `document.body` 에 따로 붙이는 폴백을 쓴다(오버레이가 이벤트를 가려 평소엔 숨은 상태). 이제 화살표 하나(기본 20px 높이, 작게/보통/크게)만 그리고 noVNC 사본은 숨긴다.
- 기본 화면은 전체 맞춤. 1:1 은 큰 Mac 해상도에서 일부만 보여 방향을 잃기 쉬웠다. 핀치로 확대하고, 확대 중 커서가 가장자리에 가면 화면이 따라간다.
- 트랙패드: 손가락 속도에 따른 가속, 탭=클릭, 더블탭=더블클릭, 두 손가락 탭=우클릭, 두 손가락 끌기=상하좌우 스크롤, 길게 누르기 또는 탭 직후 눌러 끌기=드래그.
- 게임패드 오버레이: 조이스틱(편향에 따른 속도), L/R 클릭(누른 채 조이스틱=드래그), 스크롤 버튼(길게 누르면 반복), 드래그 잠금. 투명도·크기·왼손잡이 배치 설정.
- 키보드: 입력칸 타이핑을 곧바로 전송(한글은 IME가 확정한 글자만), Enter·Backspace 는 키, ⌘⌥⌃⇧ 칩(탭 1회=다음 키·클릭만, 2회=고정), 단축키 줄(⌘C/V/X/A/Z/Tab/Space 등)과 방향키·Esc·Tab, 아이폰 클립보드 붙여넣기. 키보드 버튼 탭 안에서 포커스를 주어 iOS 가 키보드를 올리게 했다(기존 setTimeout 포커스는 iOS 에서 막힐 수 있음).
- 그 밖: 도구 줄 4초 자동 숨김과 핸들, 지연 표시(/api/version 왕복), 화면 켜짐 유지(Wake Lock), 시스템 뒤로가기 한 번 흡수, overscroll·Safari 핀치 확대 차단, safe-area, 설정은 localStorage(`ttakkari.remote-desktop.settings.v1`).
- 지연 표시는 RFB 안에서 FramebufferUpdateRequest 를 보내 재면 안 된다. 응답마다 noVNC 가 다음 요청을 하나 더 보내 요청 체인이 영구히 늘어나(검증 중 입력이 1초 넘게 밀리는 것으로 확인) HTTP 왕복으로 바꿨다.
- 검증: vitest 전체, tsc, eslint, ui-lint, build 통과. `scripts/remote-desktop/e2e.mjs` 를 합성 RFB 서버와 함께 Chromium(CDP 멀티터치 43항목)·WebKit(5항목)으로 실행. 실제 Mac·아이폰·iOS 소프트 키보드·한글 IME 조합은 미검증.

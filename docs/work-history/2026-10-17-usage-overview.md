# 계정 사용량 목록 복원

2026-10-17 사용자는 계정 하나를 선택해야 상세가 보이는 탐색 UI가 한눈에 비교하기 어렵다고 했다. 전체 계정의 사용량을 함께 표시하던 기존 목록으로 복원하고, 엔진별 색상·배지 구분은 유지하도록 요청했다.

계정 선택 탐색기와 모드 선택 단계를 제거했다. 개인·회사 섹션, 계정 순위·상태, 현재 우선 계정 요약, 기존 부문 탭을 유지한다. 각 카드에 엔진 배지와 계정 이름의 접근 가능한 라벨을 둔다. 계정 선택 없이 서로 다른 두 계정의 사용률과 Muse 카드를 함께 찾는 회귀 검사로 요청을 고정했다.

Muse `/usage`는 대화형 CLI 기능이며 SDK usage/read의 마지막 관측값과 구분한다. Muse 로그인·SDK 사용량 미관측·실행 검증 전 표시는 유지한다. 실제 구독 수치를 보지 않고 0% 또는 무제한으로 바꾸지 않는다.

검증 절차: UsageDialog 및 관련 계정/배지 테스트, TypeScript/Vite build, 기존 UI lint baseline 검사, 실제 컴포넌트의 모바일·데스크톱 합성 데이터 렌더 확인. 운영 로그인 화면의 직접 조작은 이 기록의 검증 범위가 아니다.

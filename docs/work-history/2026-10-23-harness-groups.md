# 하네스 조회 화면 2차 개편 (백엔드 ADR 0070, 2026-10-23)

## 결과
- `/harness` 를 평면 목록(카테고리 13종 칩 + 통합 검색)에서 7개 그룹 계층으로 바꿨다. 읽기 전용은 그대로다.
- 첫 화면: Claude·Codex·Muse·Qwen Code·Antigravity(메인 하네스)·따까리·프로젝트별 카드 7개(설정 있음/없음, 항목·없음·경고, 관심사별 개수) + 요약·경고 목록. 모바일은 카드 → 그룹 화면, 1024px 이상은 왼쪽 그룹 트리(선택한 그룹 아래 관심사, 프로젝트별은 프로젝트) + 본문.
- 그룹 화면: 레이어 스택(위→아래로 얹히는 순서, 근거 배지 "코드로 확인"/"엔진 동작 · 확인 필요", 숫자 칩으로 레이어·관심사 필터, 프로젝트 레이어는 프로젝트별 하네스 링크, 세션 주입 레이어는 따까리가 얹는 것 목록) → 관심사 칩(없는 관심사는 "없음"으로 흐리게) → 목록 → 상세. 항목을 열면 데스크톱은 스택을 접고 목록|상세 2단이다.
- 따까리 그룹: "관심사별 | 세션별 레이어" 탭. 기존 세션별 합성 뷰(Layers)가 여기로 이동했고 세션 주입 레이어에서 엔진을 골라 바로 들어갈 수 있다.
- 프로젝트별: 프로젝트 카드(회사 먼저, 회사 배지) → 프로젝트 → 엔진 → 관심사 → 항목(루트/하위 폴더 배지).
- 통합 검색: 머리글 검색 아이콘(`find=1`). 결과에 그룹 › 관심사 경로, 그룹 범위 칩, 경고만 보기.
- 상세: 경로(breadcrumb, 눌러서 그 그룹·프로젝트·관심사로 이동), 레이어 표시, "같은 레이어의 다른 엔진" 링크(항목 링크 또는 같은 관심사 링크).
- 상태는 모두 URL(`g c l p v item find q fg warn s le pool`).
- 구성: `pages/HarnessPage.tsx`(오케스트레이션), `features/harness/{Home,Group,Projects,Tree,Finder,Detail,Layers,nav,labels}`, `harness.css`, `api/harnessTypes.ts`·`client.ts`(그룹·프로젝트 API 3개).
- 작업 위치: 메인 checkout 의 남의 미커밋 WIP 를 건드리지 않고 origin/main 위 worktree `front-harness-view`에서 작업했다.

- `vitest run` → `Test Files 141 passed | 2 skipped`, `Tests 1354 passed | 10 skipped`(HarnessPage.test.tsx 17개로 재작성: 7개 카드, 읽기 전용, 레이어 스택·근거 배지·프로젝트 링크, 레이어 칩 필터, 프로젝트 → 엔진 → 관심사, 검색 아이콘·경로·그룹 칩, 상세 경로·대응 항목 이동, 프로젝트 경로 복귀, 긴 본문, 경고 이동, 따까리 세션별 레이어, 실패 재시도).
